# HĀSEBO Android project

This directory is the Android Studio/Capacitor shell for the HĀSEBO POS app.

## First setup

From the project root:

```bash
npm install
cp .env.android.example .env
# Edit .env and set VITE_API_BASE_URL to the deployed HĀSEBO API base URL.
npm run cap:sync
```

Then open the `android` folder in Android Studio, or run:

```bash
npm run android
```

## Build APK

```bash
cd android
./gradlew assembleDebug  # if the Gradle wrapper has been generated by Android Studio/Capacitor
```

The debug APK will be under `android/app/build/outputs/apk/debug/`.

For a release APK/AAB, configure a signing key in Android Studio and use the
release build variant.

## Important architecture note

The Android app bundles the React/Vite frontend. The existing Node/Express API
and its database remain server-side. The APK therefore requires
`VITE_API_BASE_URL` to point to a reachable HTTPS API server in production.
Do not embed `GEMINI_API_KEY` or other server secrets in the APK.
